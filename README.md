# Screenshots

This folder should contain terminal screenshots of the program in action.
Run `src/asset_inventory.py` and capture one screenshot per file below
(see `tests/test_cases.md` for the exact steps that trigger each screen):

- `01-add-asset.png` – Menu option 1, adding a new asset
- `02-display-assets.png` – Menu option 2, showing the full inventory
- `03-search-asset.png` – Menu option 3, a successful search
- `04-update-asset.png` – Menu option 4, editing an existing asset
- `05-delete-asset.png` – Menu option 5, deleting an asset with confirmation
- `06-security-summary.png` – Menu option 6, the risk/status breakdown
- `07-input-validation.png` – An invalid entry (e.g. bad Risk Level or IP address) being rejected and re-prompted

Once you've added the real screenshots, you can delete this file.
